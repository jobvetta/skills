# Jobvetta Official Agent Skills

Official AI Agent Skills (`SKILL.md`) for [Jobvetta](https://www.jobvetta.com) - compatible with Claude Code, Cursor, GitHub Copilot, Windsurf, Codex, OpenClaw, and Antigravity via [`skills.sh`](https://skills.sh).

## Install

```bash
npx skills add jobvetta/skills
```

## Included Skills

1. **`jobvetta-jobs`** (`skills/jobvetta-jobs/SKILL.md`): Search 6.5M+ live verified employer career-site job postings across 242 countries, retrieve 70+ field structured job details, and benchmark P25/median/P75 market salaries.
2. **`company-hiring-signals`** (`skills/company-hiring-signals/SKILL.md`): Enrich B2B accounts, sales prospects, and investment research with live employer hiring velocity, open headcount by department, and technology stack signals.

## API Key

Generate a free Jobvetta API key (`25` calls/day, no credit card required) at **https://www.jobvetta.com/api** and set `JOBVETTA_API_KEY=jvk_...`.
